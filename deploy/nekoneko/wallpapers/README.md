# Existing Nekoneko desktop artwork

These are unchanged copies of the artwork used in the original local project:

- `sora.png`: `assets/bot-wallpapers/sora-wallpaper.png`, SHA-256 `4c8c88ed6010639fc4c9b8a267aff607e887c11b7fcc541f35eb70707dd65c82`
- `kinako.png`: `assets/bot-wallpapers/kinako-wallpaper.png`, SHA-256 `5444963a1c411ffcd523678236157f5dcddd14ad1f25fb214ff3160f95eac3ec`

The guide reuses this existing artwork to reproduce the blue Sora and orange
Kinako desktops. `wallpaper.mjs` installs it only into the recorded guide Bot's
running desktop. Run the team's setup again after recreating a desktop to
restore its wallpaper. Applying the wallpaper does not close browser windows.
