# カスタムマスコットの視覚受け入れ

**判定: PASS（視覚受け入れ）**

作成フローと保存済みマスコットの利用を、実画面のキャプチャと12.4秒の録画で確認しました。推奨掲載画像は 19-creator-final.png です。操作欄の拡大には 20-creator-panel-final.png を使ってください。

## 画面の確認

- 作成欄にSVG選択、名前、アニメーションプレビュー、顔の位置と大きさを調整する3つのスライダー、範囲内の表示、保存ボタン、保存済み一覧が並びます。420×980の拡大画像でラベルとボタンを読めます。
- 1024×768では横方向のはみ出しがありません。3つのスライダーと有効な保存ボタンが画面内にあり、各スライダーの右端はx=982です。撮影時は設定パネルを縦にスクロールしているため、プレビュー上部は画面外にあります。
- カスタムうさぎは丸い輪郭で表示され、四角い画像枠には入っていません。Fixture Starterの緑のカーソル形はそのままです。Juniperは明示的な再利用操作のあとで赤いうさぎを表示します。四角形の「まきまる」は別の保存項目です。
- 表情、色、胴体形状の標準選択肢も残っています。保存後、Atlasには2件、Juniperには1件のカスタム形状があり、Fixture Starterにはありません。
- 顔を範囲外へ動かすと警告が出て、保存が無効になります。SVGの検証記録では、スクリプトを含むファイル、壊れたファイル、上限を超えるファイルを拒否し、下書きを保持しています。記録上、スクリプト実行と外部通信はありません。
- 録画の5サンプルでは、working、thinking、happyの顔パスがそれぞれ異なり、胴体パスは共通です。2つのcreator-gazeサンプルは同じパスでした。ポインター追従を示す証拠としては扱いません。

## 保存と再起動の記録

保存、再選択、別ボットへのコピーはHTTP 201を返しました。再起動前後のプロフィールJSONは記録上同一です。これらは証跡ファイルによる確認です。

## 制限

この判定は視覚受け入れに限ります。別のElectron環境とモバイル環境は確認していません。

full-tests.logではserver/index.test.tsの278件中206件が失敗、8件がスキップされ、その後のserver/org-library.test.tsにも失敗が記録されています。この視覚確認では原因を調べていません。ログは実行中テストによりロックされているため、SHA-256一覧から除外しました。
